# Group Project: Interactive Dashboard

## Instructions

Create an interactive dashboard using data analytics tools and techniques.

The dashboard must meet the following requirements:

1. It must be accessible online.
2. It must use a published dataset, not a dummy dataset.
3. It must include interactivity.

## Required Dashboard Components

The dashboard must contain:

1. **Interactivity**
2. **A tab explaining the important components of the dashboard**
   - Example: What problem or problems the dashboard can address
3. **A link to the dataset source**

## Submission Notes

1. Paste the dashboard URL in the text editor provided under the **Group Project Submission Link**.
2. Refer to the rubric in the course syllabus to understand how the submission will be graded.
3. All group members must submit. Submissions will not be counted unless all members click the submit button.
